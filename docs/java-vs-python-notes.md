# Java vs Python Notes

Use this file as a running migration log.

## Week 1 starter notes

1. Python variables are names bound to objects, not typed slots that own values.
2. Python functions are often enough; not every behavior needs a dedicated service class.
3. List and dictionary comprehensions replace a lot of verbose loop and temporary variable code.
4. Package layout is lighter than Java's class-per-file convention.
5. Exceptions should be meaningful domain signals, not a blanket wrapper around every branch.
