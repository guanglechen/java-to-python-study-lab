# 课程介绍讲稿 | Course Intro Script

## 中文主讲

你好，这个学习项目的目标，不是把 Python 当成脚本语言随便用一下，而是把它真正学成一门工程语言。

你的优势很明显。你已经熟悉 Java 的工程化、数据库、缓存、中间件和消息系统。所以这套课程不会把重点放在初学者式的语法扫盲，而是放在迁移上。也就是，如何把你已经很强的工程经验，快速翻译成 Python 的表达方式。

整个训练会分成 8 个阶段，每个阶段按 Day 节奏推进。

第 1 阶段和第 2 阶段，只做语言迁移。重点不是记语法，而是理解 Python 的变量绑定、函数优先、集合处理、异常设计、模块组织，以及哪些写法是 Pythonic，哪些写法虽然能跑，但本质上还是 Java 思维。

第 3 阶段会补工程化工具。你会开始接触 pyproject.toml、依赖管理、测试、类型检查和日志规范。到这里为止，你要建立的不是脚本能力，而是项目能力。

第 4 阶段和第 5 阶段进入后端主线。我们会用 FastAPI、数据库和 Redis 做一个小型服务。你的重点不是重新学数据库，而是理解 Python 后端项目如何组织、依赖注入怎么写、数据模型怎么拆、测试怎么设计。

第 6 阶段开始进入 AI 应用工程。先做模型服务接入，再做最小 RAG。这里最重要的不是框架，而是边界。你要知道模型调用、检索、上下文组装和 API 层为什么不能混写。

第 7 阶段会补图数据库和知识图谱。目标不是把图谱做复杂，而是让你知道什么问题适合向量检索，什么问题更适合图查询。

第 8 阶段做 Agent 和工作流编排。这个阶段才会看 LangChain 或 LangGraph，但重点仍然不是会调框架，而是会做状态管理、工具边界、重试、缓存和审计。

所以，这门课的目标很明确。不是让你学会几个 Python 语法点，而是让你完成一次工程认知迁移。从 Java 工程师，切换成能做 Python 后端和 AI 应用的工程师。
